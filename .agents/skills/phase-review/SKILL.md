# Phase Review Skill

Use this skill at the end of each phase.

## Review Deliverables
Produce a structured summary covering:
1. **Files Changed**: List all files added, modified, or deleted.
2. **How to Test**: Step-by-step verification commands and test steps.
3. **What Could Break**: Risk analysis and regression possibilities.
4. **SonarQube Result**: Summary of SonarQube scan findings, fixed issues, and any flagged items.
5. **CodeRabbit Result**: Summary of CodeRabbit pull request review comments and resolutions.
